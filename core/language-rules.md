# Core · language-rules（通用中文技术表达规则）

> 迁移自 V0.2 `SKILL.md` 3.1／3.2／3.3／3.4 与 `references/expression-issues.md` 第一至三节。按 D-2，本文件不含学科专属术语清单；学科示例统一放在各 Domain Pack 的测试集中。

## 1 目标与核心原则

规范表达，而不是限制表达；纠正真实问题，而不是制造新的写作模板。

在不改变科学含义与技术信息的前提下，使中文表达准确、自然、清晰。原文已准确、自然、简洁时，直接交付，不作修改。

## 2 分级与判定顺序

| 级别 | 定义 | 处置 |
| --- | --- | --- |
| Error | 明确的语言、术语或语义错误；影响事实、逻辑或科学含义 | 必须纠正，且只作最小改动 |
| Warning | 机械直译、伪专业词汇、互联网黑话、冗余、歧义、不合理的逻辑结构 | 建议修改；语境可解释时记「待确认」，不改写 |
| Suggestion | 文体与表达偏好 | 由上下文决定，默认不改 |

判定顺序：先确认是否属于保留项或正确表达 → 再判 Error → 再判 Warning → Suggestion 不改动。

## 3 误判控制

- 词形命中不等于违规，须结合语境复核。
- 不设句长、段落长度、标题层级、清单项数、连接词数量、注释行数、「的」字数量、否定次数的硬性阈值。
- 长句、多重定语、被动式、多重否定、多连接词、第二人称、并列词形混用，均为合法中文结构；仅凭这些特征不得判为 Error。
- 缺少依据或语境信息时判「待确认」，不改写。
- 不得为「统一」而替换文献中实际使用的词形。
- 原文已准确、自然、简洁时，允许且不推荐任何修改。

## 4 Error 级

每条含「不构成违规的情形」。学科专属示例见各 Pack 的 `tests/cases.json`。

- **E1 含义改变**：改后科学含义、技术事实、因果方向或结论边界变化 → 回退。不构成违规：原文未改。
- **E2 确凿字形错误**：如阀值→阈值、布署→部署、做为→作为、反回→返回 → 纠正。不构成违规：引用原文、专有名称、代码字符串。
- **E3 单位与符号**：法定计量单位符号、量符号被改写；或原文缺单位被臆造补齐 → 保留原数值、标注「单位待核」。不构成违规：无量纲量、编号、计数、公式内量。
- **E4 概念混淆**：把计量学中不同定义的评价量当作同一量互换，或把能量与速率混用 → 纠正并说明概念差异。不构成违规：术语登记表中标为并存词形的条目。
- **E5 证据强度**：推测、初步结论被写成确定事实，或「可能／通常／初步／待确认」被删除 → 恢复。不构成违规：作者已给出判据的确定性结论。
- **E6 条件缺失**：条件、限定、例外、忽略项、误差说明被删去 → 恢复。不构成违规：原文确无限定。
- **E7 指代与否定**：指代造成事实对象错误、否定范围改变 → 纠正。不构成违规：指代唯一、否定清晰。

## 5 Warning 级

每条含「可保留的语境」。

- **W1 机械直译框架**：被…所…、对…进行了…、基于…的基础上、通过…的方式、具有…的性质、无数量含义的「一个／一种」。可保留：学术文献常见结构且不影响理解时。
- **W2 伪专业词汇与黑话**：赋能、抓手、闭环、拉通、对齐、颗粒度、跑一下、调一调、拍脑袋等。可保留：已定义且有固定含义的内部术语。
- **W3 冗余与虚化动词**：信息密度低、动作对象不明。可保留：并列动作、强调或节律需要。
- **W4 模糊限定修饰结论**：显著、基本、大致、良好、可靠、有效、适当等无判据。可保留：定性描述、引述他人结论、已给判据。
- **W5 歧义**：并列层级不清、代词无唯一先行词、比较无基准、结论无适用范围。可保留：语境已能消歧。
- **W6 不合理的逻辑结构**：因果倒置、相关写成因果、条件与结论脱节、对比框架两项不互斥。可保留：说明性修辞对比。
- **W7 无理由换词**：同一文档内同一概念换用并存词形，易致误解。可保留：两词含义不同且已分列语境。

## 6 Suggestion 级（默认不改）

- 标点全半角、中西文留白、引号样式 → 按项目约定。
- 段落划分、标题层级、清单结构、结论是否前置 → 按文体与读者。
- 人称、第二人称、语气强度、情态词择一 → 按文体。
- 句长、句式、主动或被动、连接词选择 → 由语义完整性决定。
- 铺垫语与元评论 → 由交际目的决定；过程汇报场景可保留。

## 7 表达问题词形（Warning 提示，非禁用）

### 7.1 机械直译与冗余框架

| 表达 | 建议 | 可保留的语境 |
| --- | --- | --- |
| 对…进行了…／对…作出了… | 具体动词＋宾语 | 学术文献常见结构，不影响理解时 |
| 被…所…／由…所… | 中文话题式陈述，或写出施事 | 受事为主语、施事不必出现时 |
| 基于…的基础上／就…而言 | 依据…／关于… | 引述固定译法时 |
| 通过…的方式／手段 | 用…／按… | 强调方式本身时 |
| 具有…的性质／特征 | 是…／表现为… | 定义性表述中作分类用语时 |
| 实现了…的优化／作出了改进 | 写明改前值、改后值与评价量 | 概述性文字且后文给出数据时 |
| 无数量含义的「一个／一种」 | 删除或写明实际数量 | 学术写作中作类指且不影响理解时 |
| 使／让＋无生命主语＋动词 | 写明作用关系与条件 | 说明性比喻且事实关系清楚时 |
| 值得一提的是／众所周知／不难看出 | 直接陈述或写明出处 | 面向过程汇报、教学讲解时 |

### 7.2 伪专业词汇与互联网黑话

| 表达 | 建议 | 可保留的语境 |
| --- | --- | --- |
| 赋能／抓手／闭环／颗粒度／拉通／对齐／沉淀 | 写出具体对象、动作与完成判据 | 已定义且有固定含义的内部术语 |
| 跑一下／跑通／调一调／调参 | 写明具体工作、系数取值与依据 | 日常交流中双方已明确所指时 |
| 拍板／拍脑袋／差不多就行／经验值 | 写出决议主体、依据来源或允许偏差 | 引述会议发言原文时 |
| 兜底／打样／喂数据／踩坑／玄学／手感 | 写出现象、条件、影响与责任主体 | 引用原文或作为例证时 |
| 这个 case／做个 check／未定义的中英夹杂缩写 | 写出对象全称与具体动作 | 引用界面原文或外部材料时 |

### 7.3 歧义与逻辑

| 情形 | 建议 | 可保留的语境 |
| --- | --- | --- |
| 显著／基本／大致／良好／可靠／有效／适当 修饰结论且无判据 | 补判据、比较基准或删除 | 定性描述、引述他人结论、已给判据 |
| 近似／忽略 未给误差界或量级 | 写明忽略依据与影响范围 | 前文已给出量级估计 |
| 提高／降低／改善／优于 无基准 | 写明比较基准与量 | 方向性描述且后文给出数据 |
| 其／该／此／上述 指代对象不唯一 | 重复名词 | 指代唯一且清晰 |
| 和／与／及／以及 并列层级不清 | 分组或改用清单 | 语义与语体本就要求不同连接词 |
| 对比框架两项不互斥 | 分项陈述 | 说明性修辞对比，两项可同时成立且无事实争议 |
| 因果倒置、相关写成因果、条件与结论脱节 | 分项陈述并写明依据 | 已标注为推测或假设 |
| 同一文档无理由换用并存词形 | 择一并登记 | 两词含义不同且已分列语境 |

## 8 已移除的机械判据（防回退记录）

以下特征在 V0.2 已明确不再作为错误或改写理由；Core 不得重新引入。

| 特征 | 旧处置 | 现行处置 | 依据 |
| --- | --- | --- | --- |
| 单句超过 40 汉字、代码注释单行超过 30 汉字 | 不符合 | 不判 | 长句可承载完整条件与限定 |
| 段落 3–5 句、≤ 200 汉字；单节 ≤ 5 段 | 不符合 | 不判 | 段落与章节长度由论述结构决定 |
| 标题超过 3 级、清单 3–7 项以外 | 不符合 | 不判 | 由文档结构与读者决定 |
| 连续「的」≥ 3 | 不符合 | 建议项 | 多层定语在科技文献常见 |
| 一句内否定超过一处、转折超过一处 | 不符合 | 不判 | 多重否定与多重转折为合法结构 |
| 和／与／及／以及 并列混用 | 禁用 | 不判（歧义时为 Warning） | 各词语义与语体有别 |
| 「被＋动词」 | 不符合 | 建议项 | 受事为主语时中文被动自然 |
| 第一人称「我们」、第二人称 | 禁用 | Suggestion | 由文体与交际目的决定 |
| 无数量含义的「一个／一种」 | 禁用 | 建议项 | 学术写作常见且不影响理解 |
| 术语词形唯一化，禁用文献并存的词形 | 禁用 | Warning（同文档一致） | 缺少依据时不得禁止合法用法 |
| 输出工作模式、审查过程、校验结论 | 强制 | 默认不输出 | 仅在用户要求审查记录时提供 |
