# Core · quality-control（原文保护、按需审查与测试规范）

> 迁移自 V0.2 `SKILL.md` 1.2、`references/review-record-template.md`、`references/examples.md`。示例保留原文中的学科语境，仅用于校准改写尺度，不构成术语规则（D-2）；各 Pack 的学科用例见其 `tests/cases.json`。

## 1 保留项（Error 级保护）

改动后下列任一项发生变化，判为 Error 并回退：

1. 科学含义、技术事实、物理关系与因果方向。
2. 公式、量符号、上下标、正斜体、运算符、单位符号、数值、有效数字、不确定度。
3. 限定条件、适用范围、假设、例外、忽略项及其量级理由。
4. 证据强度：可能／通常／初步／待确认／据…等表述不得删除或改为确定。
5. 结论边界：比较基准、评价量、适用工况、时间范围。
6. 既有标准译名、学科审定名词、专有名称、机器可读内容、引用原文。

规则检查与替换只作用于可见中文正文；保留项内部不作字形、留白或大小写处理。

## 2 按需核对点

逐项回答「是／否／不适用」；任一项为「否」须定位并最小改写。本清单不要求输出给未请求的用户。

- [ ] 科学含义、技术事实、因果方向未改变。
- [ ] 公式、符号、上下标、正斜体、单位、数值与有效数字保持原样。
- [ ] 限定条件、适用范围、假设、例外、忽略项及其量级理由未被删除。
- [ ] 证据强度（可能／通常／初步／待确认／据…）未被删除或改为确定。
- [ ] 结论边界（比较基准、评价量、适用工况、时间范围）未扩大。
- [ ] 既有标准译名、学科审定名词、专有名称与引用原文保持原样。
- [ ] 机器可读内容与保留项内部未作字形、留白或大小写处理。
- [ ] 未臆造原文没有的单位、数值、判据、条件或结论。
- [ ] 未把正常中文结构（长句、多重定语、被动、多重否定、连接词差异）判为错误。
- [ ] 未因词形偏好禁用文献中实际使用的并存词形。
- [ ] 强制性术语规定均附有依据类别；无依据者已降为 Warning 或仅登记。
- [ ] 原文已准确、自然、简洁的段落未作修改。
- [ ] 所有改写均为最小改动，且未引入新的写作模板。
- [ ] 归档版本未被追溯修改；变更已登记「原词形 → 新词形」。

## 3 误判类型

| 类型 | 定义 |
| --- | --- |
| 过度修改 | 正确表达被改写，或原文已准确时仍作改动 |
| 漏判 | 真实 Error 未纠正 |
| 分级误判 | 边界案例被判为 Error 并强制改写，或 Warning 被当作必须修改 |
| 依据误判 | 无依据的词形被当作强制术语规定 |
| 保真误判 | 改写改变了科学含义、技术事实、证据强度或结论边界 |

## 4 按需审查记录模板（仅用户要求时输出）

```text
范围：<本次处理的文本范围>
文本类型：<代码注释／技术文档／科研申请书／技术报告／项目材料／日志与错误提示／日常技术交流>
加载模块：<Core + 已加载的 Pack 与 Profile>

Error（已纠正）：位置｜原文｜级别依据｜最小改写｜保留项核对
Warning（建议）：位置｜原文｜建议｜处置（改写／待确认／保留）｜理由
Suggestion（默认不改）：位置｜偏好项｜是否采用｜理由
未改写项：位置｜原文｜判定为正确表达的依据
误判登记：用例编号｜观测处置｜期望处置｜误判类型｜修正措施
```

## 5 校准示例（22 条，保留 V0.2 原文）

### 5.1 正确表达（不修改）

1.（技术文档）「在壁面温度低于给定上限且辐射传热可忽略的条件下，按稳态导热关联式计算通过多层平壁的热流密度。」→ 不修改。长句承载完整条件，拆分会割裂限定关系。
2.（技术文档）「用于高温条件下壁面热流密度测量的新的标定方法的适用范围见第二节。」→ 不修改。多层定语在科技文献中常见且指代清楚。
3.（技术报告）「温度、压力与流量以及壁面状况均需记录。」→ 不修改。并列连接词的语体差别不影响语义。
4.（技术文档）「热导率取材料表数值，并随温度修正。」→ 不修改。该词形在文献中并存。
5.（论文稿件）「本文对壁面温度进行了测量，并对测量结果进行了分析。」→ 不修改。学术写作常见结构，动作对象明确。
6.（日志与错误提示）「你可以在结果页查看每次测量的偏差。」→ 不修改。第二人称由界面文体决定。
7.（技术报告）「系统在通常工况下达到稳态。」→ 不修改。「通常」是证据强度的一部分。
8.（日常技术交流）「这组数据先按上一版的方法处理，等标定结果出来再定系数。」→ 不修改。日常交流仅适用 Error 级。

### 5.2 真实错误（Error，纠正且只作最小改动）

1. 原文「温度为 300，压力 2。」错误做法：改写为「温度是 300 K，压力是 2 MPa」。正确处置：保留原数值，标注「单位待核」，不臆造单位。依据 E3。
2. 原文「在适当条件下可忽略辐射传热。」错误做法：改写为「可以直接忽略辐射传热」。正确处置：恢复条件；条件不明确时标注待补。依据 E6。
3. 原文「结果偏差可能是设备问题导致的。」错误做法：改写为「结果偏差是设备问题导致的」。正确处置：恢复「可能」。依据 E5。
4. 原文「误差与测量不确定度按同一公式计算。」正确处置：分列两个概念并写明各自评定方式。依据 E4。
5. 原文「阀值按上一版取值。」正确处置：纠正为「阈值」。依据 E2；若属引用原文则不改。
6. 错误做法：把公式中的量符号 λ 统一改写为中文「导热系数」，并调整下标。正确处置：公式与符号属保留项，原样保留。依据 1.2、E3。
7. 原文「计算值与实验值基本吻合，说明模型可靠。」错误做法：改写为「模型完全可靠」。正确处置：恢复限定词与结论边界。依据 E5、E6。

### 5.3 边界案例（Warning 或待确认，不硬改）

1.「按项目约定的「闭环」检查项逐项核对。」→ 记「待确认」，不改写。
2.「在允许偏差 2% 内，计算值与实验值吻合。」→ 不改写，已给出判据。
3.「该改动针对写法，不针对技术结论。」→ 不改写，对比用于澄清范围。
4.「Re 增大时 Nu 随之变化。」→ Warning：建议首次给出中文全称，不判 Error。
5.「导热系数取材料表数值，热导率随温度修正。」→ Warning：提示同一文档内保持一致，不禁止任一词形。
6.「用于高温条件下壁面热流密度测量的新的标定方法被记录在系统所生成的文件中。」→ Warning 建议项，语境可保留。
7.「显著降低了操作复杂度。」→ Warning：建议补评价量；属定性描述且无事实争议时保留。

## 6 测试规范

- 通用执行器位于 `tests/run_tests.py`，接受模块目录或用例文件参数。
- 每组测试须包含正例、反例、边界案例；评审方为规则制定方时须标注同源偏差。
- 集成用例位于 `tests/integration.json`，用于组合与误用检测。
- 回归基线：V0.2 的 25 条用例与误判记录不因迁移而减少。
