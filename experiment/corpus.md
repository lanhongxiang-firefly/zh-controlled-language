# 实验语料与判定基准

本文件是「工程热物理中文受控语言 Skill 有效性验证」的全部原始数据。三组文本含义相同、处理方式不同：

- **A 原始**：按常见中文技术写作习惯写成，植入已登记的缺陷。
- **B 顺化改写**：只求通顺自然的常规润色，不套用任何规则；允许为流畅而删条件、合并术语、补单位、把推断写成事实。
- **C 受控改写**：严格按 `SKILL.md` 的六节规则作最小改写；缺失的判据、单位、条件一律显式标注待补，不臆造。

三组文本均只含文字表述，不含代码块、公式、图形；代码注释样本以逐行文字给出，块注释允许多行。

## 样本 1｜技术文档

### A 原始
```text
众所周知，对壁面温度进行了测量，并对测量结果进行了分析。实验数据被记录在系统所生成的文件中。导热系数取材料表数值，热导率随温度修正；放热系数按关联式计算，对流换热系数按另一工况给出。在适当条件下可忽略辐射传热，计算结果与实验值基本吻合，精度较好，说明模型是可靠的。温度为 300，压力 2，热流密度较大。雷诺数（Re）由测量值给出，努塞尔数（Nu）按关联式计算；同一组数据在后文又写作 re、R.E. 与 NU。需要检查温度、以及压力以及流量和壁面状况等相关参数。本文提出了用于高温条件下壁面热流密度测量的新的标定方法。
```

### B 顺化改写
```text
我们测量了壁面温度并分析了数据，实验结果也写进了文件。材料的导热性能按温度作了修正，换热系数按公式算出。辐射影响很小，可以直接忽略，所以结果和实验很接近，模型没有问题。温度是 300 K，压力是 2 MPa，热流密度偏高。Re 与 Nu 都由测量得到，后文统一用这两个符号就行。还要核对温度、压力、流量和壁面状况等几项。本文提出一种新标定法，用于高温下壁面热流密度的测量。
```

### C 受控改写
```text
测量壁面温度，并分析测量结果。实验数据写入数据文件。导热系数取材料表数值，并随温度修正。表面传热系数按关联式计算；另一工况下的取值须单列，并写明该工况的条件。辐射传热的忽略判据须在文中写明；判据成立时，可不计辐射传热。偏差须给出允许偏差后才能判定。模型的适用范围限于已写明条件的工况。温度取 300，压力取 2；原文未给出单位，须回查后补齐，不得据文臆造。热流密度须给出上限值后才能判断。雷诺数（Re）由测量值给出，努塞尔数（Nu）按关联式计算；后文统一只用 Re 与 Nu。需核对以下四项：温度、压力、流量、壁面状况。本文提出新的标定方法，用于测量高温条件下的壁面热流密度。
```
