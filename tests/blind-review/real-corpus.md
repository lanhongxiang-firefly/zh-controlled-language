# 真实项目文本语料登记规范

## 1 选取标准

- 来自真实科研或工程项目，并非为检验规则而构造。
- 覆盖至少 3 类文本：代码注释、技术文档、项目材料或技术报告。
- 单条 50–300 字，总数不少于 20 条；准确表达、含真实语言问题的样本与边界样本分列。
- 保留原始写法，不预先按本规范改写；不得为了让规则表现更好而挑选样本。

## 2 登记字段

| 字段 | 说明 |
| --- | --- |
| `id` | `RC-001` 起顺序编号 |
| `source_type` | 代码注释／技术文档／技术报告／项目材料／日志与错误提示 |
| `origin` | 来源项目或文档类型描述，不含具体项目标识 |
| `authorization` | 自有／已获授权／公开可引用／已脱敏 |
| `sensitive` | 是否含需脱敏的数据、数值、专有名称或设备代号 |
| `text` | 原文，脱敏位置以 `[已脱敏]` 标注 |
| `notes` | 语境说明；不写期望判定，避免向评审方泄露答案 |

语料按 `corpus-template.json` 登记为同目录的 `corpus.json`；`generate_materials.py` 与 `summarize.py` 检测到该文件时自动纳入，用例编号前缀为 `real-corpus:`，汇总时按模块单独列出用例数与误判数，不与构造语料合并统计。

真实语料的期望判定须由独立标注方给出，或只统计评审方之间的一致性；不得由规则制定方自评为金标准后再宣称完成了独立盲评。

## 3 约束

- 不登记未获授权的文本、未公开的设备或项目标识、真实测量数值。
- 脱敏只删除标识，不改变语言现象；不得以脱敏为由修正原文中的语言问题。
- 真实语料的盲评由独立评审方按 `protocol.md` 执行。
- 登记语料前确认许可状态：第三方材料遵循原有权利状态，不按本项目许可重新授权。
